## Baseline findings and recommended controls

**S2-HISTORY-001, required entry correction.** Both actual pure adapters pass awards, Award Notification and Awarded into SUPPORTED_CAPABILITY_AWAITING_JUDGMENT. Award Notice, award and a stay historical despite a 2099 deadline. Outer spaces/case are already tolerated for canonical labels; repeated internal spaces, tabs or newlines are not. Preaward, pre-award, Solicitation, contract and unknown/blank controls are not historical. Every fixture also mentions a prior award in its narrative, confirming narrative text does not drive the current type detector.

The chosen field is top-level notice_type, then top-level type, raw.type, raw.base_type, with truthiness applied before stripping. Therefore a whitespace-only top-level value can shadow a native award label; a conflicting top-level Solicitation wins over raw Award Notice without a conflict marker. API camelCase baseType is retained but not read by this fallback; CSV base_type is read. The separate type/base-type fields may describe different lifecycle concepts, so disagreement must remain attributed rather than being flattened by an any-award-substring rule. Actual alternate-label prevalence in live SAM data was not measured.

Minimum correction: normalize comparison values with case folding and whitespace collapse; match an explicit closed historical alias set. Preserve original field paths/values plus selected field, normalized value and conflict status in an additive receipt. Native current type should not silently be overwritten by a compatibility projection; absent/fallback and contradictory cases need an explicit policy. Never classify Preaward by substring or infer history from a narrative mention. Preserve original rows, capability spans and historical research access. This is separate from general Step3 entailment.

**S3-ROLE-001, semantic role absent.** Requested software/SOW deliverables, projector SPRS evaluation, manufacturing guidance, negation, quoted prior work, an unregistered company-name collision and mixed negative clauses all produce CORE evidence in the fixtures. Most enter the same review stage. Thin text, title-only and missing material SOW also cannot establish requested support. The known APEX Gamma collision still excludes correctly, and genuine-work-shaped canonical/alias controls survive. These observations establish a missing semantic distinction, not that actual model triage or strict release accepted all negatives.

Add conservative per-span role evidence adjacent to the existing matcher: requested deliverable/technical requirement; evaluation/eligibility boilerplate; reference guidance; historical/quoted work; negation; identity collision; unresolved or contradictory context. Retain mixed roles independently. Do not globally blacklist SPRS, supplier risk, guidance or healthcare words. A cited guide explicitly incorporated as contracted work can support a requirement; a bare reference cannot. A not-only construction must remain a positive control. Keep lexical retrieval/score receipts; use a separately named requested-support decision for downstream claims. Unresolved material context is a research gap, not a confident functional rejection or automatic model escalation.

**S3-CONTEXT-002, first-hit and context loss.** A long mixed notice retains only its first boilerplate occurrence; a term in the title suppresses all description hits. An API narrative can be discarded from the model context even after it supplied deterministic evidence. Fixing semantic filtering without these retention paths risks discarding a later genuine SOW requirement. Extend bounded evidence collection to retain distinct clause/section contexts and original offsets with field/hash, capture length, truncation/overflow and source identity. Under a cap, record unresolved coverage instead of certifying boilerplate-only. Carry the decisive role/support references through triage; preserve amendment source IDs and never promote an earlier superseded positive over a later withdrawal without an explicit current-source decision. Combined attachment text remains discovery-only; do not invent per-file passage attribution from a bundle.
